My work

My colors

  • Page background: #4cc46a
  • Text: #f700d6
  • Headings: #fa09da
  • Links: #faf7f7
  • Accent: #ffffff

My font

My font is Arial, sans-serif. I used it on the whole page (it's in my body rule).

Rules I wrote

Rule 1

body {
       margin: 0;
       padding: 0;
       font-family: Arial, sans-serif;
       background-color: #4cc46a;
       color: #f700d6;                         
       line-height: 1.75;
       box-sizing: border-box;
       min-height: 100vh;
       display: flex;
       flex-direction: column;  
       justify-content: space-between;
       text-align: center;

   }

Without it, my page would be very boring and lame.

Rule 2

h1 {
       font-size: 3rem;
       margin-bottom: 1rem;
       color: #fa09da;  

   }

It changes the color on every page.

Rule 3

h2 {
       font-size: 1.7rem;
       margin-bottom: 0.5rem;
       color: #fa02d9;
   }

Without it, my page would be black and white.

My class

a:hover {
       color: #faf7f7;
   }
   a:visited {
       color: #ffffff;
   }
   a:active {
       color: #ffffff;
   }

I used it to align my work. I used a class so only my page gets this style.

What I'd change now

I'd change my background color because its very dull.
